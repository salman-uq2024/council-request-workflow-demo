# Screenshots

Add screenshots to this folder after running the app locally.

Recommended files:

- `01-dashboard-overview.png`
- `02-request-submission.png`
- `03-admin-review.png`
- `04-audit-history.png`

Suggested capture notes:

- Use a browser width that shows the full desktop layout
- Capture seeded data before reset so the dashboard looks populated
- Include one screenshot after submitting a new request
- Ensure the admin review screenshot shows action controls and business detail
- Ensure the audit screenshot shows both the recent activity feed and a selected request timeline

You can then reference the images in the main `README.md` if needed for a portfolio site or job application.
